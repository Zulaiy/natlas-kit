## Package setup

Build the packages with `pnpm build:packages`. The React workspace package is `@natlaskit/react`. It depends on `natlaskit` and React 19. Both SDK packages are source releases; use the workspace or packed local tarballs until publication.

## A transcription interface

```tsx
'use client';
import { useCallback, useState } from 'react';
import { AudioRecorder, TranscriptionPanel, useTranscription } from '@natlaskit/react';

export function SpeechInput() {
  const [audio, setAudio] = useState<Blob | null>(null);
  const { transcribe, job, status, error, busy } = useTranscription({
    baseUrl: '/api/speech',
  });
  const onAudio = useCallback((blob: Blob) => setAudio(blob), []);
  return <>
    <AudioRecorder onAudio={onAudio} disabled={busy} />
    <button disabled={!audio || busy}
      onClick={() => audio && transcribe(audio, 'english')}>
      Transcribe
    </button>
    <TranscriptionPanel text={job?.text} status={status} error={error} />
  </>;
}
```

The Next.js example in `examples/nextjs-transcription` includes the client component. Reuse the proxy in `apps/web/app/api/speech/[...path]/route.ts` and set server-side `NATLAS_API_URL` and `NATLAS_API_KEY`.

## Components

| Component | Key props |
| --- | --- |
| `AudioRecorder` | `onAudio`, `disabled`, `maxSeconds` |
| `AudioUploader` | `onAudio`, `disabled`, `className` |
| `LanguageSelector` | `value`, `onChange`, `disabled`, `className` |
| `TranscriptionPanel` | `text`, `status`, `error` |

The package exports semantic HTML with `nk-*` classes; include your own styling. The website stylesheet is a reference implementation.

## Hooks

`useRecorder()` provides recording, elapsed time, audio, permission errors, start, stop and clear. `useTranscription()` provides job state, errors, submission, busy state and reset.

Microphone recording requires HTTPS or localhost. Every active microphone track is stopped when recording ends or the component unmounts. Use a stable `onAudio` callback.
