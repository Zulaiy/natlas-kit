## What to test

Ask a developer outside the core team to follow the quickstart, complete a real N-ATLAS transcription and reuse one SDK call or React component in a small application. Record their setup time, environment, language, official model ID and any assistance or failures.

Test with consented recordings and an authorised official model. The playground's illustrative landing-page transcript and automated test fixtures do not provide real-model evidence.

## Save useful evidence

Keep a sanitised screen recording, screenshot or log showing the actual result. Record the toolkit commit and model revision. Separate local CPU setup from tests using a hosted backend. Do not publish credentials, private audio or a tester's identity without consent.

The [session procedure and evidence template](https://github.com/Zulaiy/natlas-kit/blob/main/benchmarks/beta-testing.md) provide tasks and fields for each tester.

## Challenge requirements

The [official Developer Infrastructure requirements](https://ncair.nitda.gov.ng/naic/#eligibility) require at least two external beta testers and a working N-ATLAS integration. Real-model measurements and external sessions still need to be recorded for this release.
