natlaskit is an independent toolkit for N-ATLAS speech recognition: a Python SDK, TypeScript SDK, React components, and a CPU backend.

## Release status

<SourceRelease />

This is a source release. Packages are not yet published to npm or PyPI. The website can run without a speech backend, but live transcription requires the official model access and local inference dependencies. There is no simulated transcription mode.

The four model adapters are configured. Language quality, CPU latency, and real-model inference must be validated with actual recordings; no benchmark results are claimed.
